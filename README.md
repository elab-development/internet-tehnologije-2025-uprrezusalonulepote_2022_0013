# Aplikacija za rezervaciju termina u kozmetičkom salonu

## Opis projekta
Web aplikacija namenjena upravljanju i rezervaciji termina u kozmetičkom salonu. 
Korisnici mogu da pregledaju dostupne termine, izvrše rezervaciju, registruju se i prijave na sistem, dok administrator ima mogućnost upravljanja terminima, korisnicima i rezervacijama.

## Funkcionalnosti
- Registracija i prijava korisnika
- Rezervacija termina
- Pregled i upravljanje rezervacijama
- Administratorski panel
- Autentifikacija i autorizacija po ulogama

## Tehnologije
- Next.js
- React
- TypeScript
- Node.js
- PostgreSQL
- Drizzle ORM
- Docker

## Pokretanje aplikacije lokalno

1. Klonirati repozitorijum:
git clone <link-repozitorijuma>

2. Instalirati zavisnosti:
npm install

3. Pokrenuti aplikaciju:
npm run dev

Aplikacija je dostupna na:
http://localhost:3000
- feature/backend
- feature/frontend
